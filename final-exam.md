# final git exam
 
this file summarizes the complete git and github workflow

check the current directory with pwd
2.check the current branch with git branch
3.check the working tree with git status
4.pull the latest main before starting work
5.create a feature branch for a new task
6.modify project files on the feature branch
7.use git diff to review changes
8.use git add to stage changes
9.use git commit to save a clear local version
10.push the feature branch to github
11.open a pull request from the feature branch to main
12.use closes #number to connect the pr with an issue
13.update the same pr by pushing more commits to the same branch
14.merge the pr after review
15.pull main locally after the pr merged on github
16.delete finished feature branches
17.use tags to mark important versions
18.keep the repository clean and synchronized
