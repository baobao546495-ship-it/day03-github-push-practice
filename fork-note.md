# fork note

fork means copying somone else is github repository to your own github account
clone means copying a github repository to your local computer
branch means creating a separate line of work insaide one repository
in open source projects, contributors usually fork first, then clone their own fork
origin usually points to your own fork
upstream usually points to the original repository
contributors push changes to their own fork and open a pull request to the original repository
the original project maintainer decides whether to merge the pull request
